# web

웹 기초와 C++ 연습 파일을 넣어 둔 저장소입니다.

## HTML 연습 (루트 및 `d/`)

기초 HTML/CSS/JS를 소개하는 3페이지 구성입니다. `web.html`이 목차 역할을 합니다.

| 파일 | 내용 |
|---|---|
| `web.html` | WEB 소개 + HTML / CSS / JavaScript 링크 |
| `1.html` | HTML |
| `2.html` | CSS |
| `3.html` | JavaScript |
| `d/` | 위 4개 파일의 사본 |

실행: `web.html`을 브라우저로 열기 (링크 색상 CSS, 외부 이미지 URL 사용).

## C++ 연습 (Visual Studio 솔루션)

| 폴더 | 내용 |
|---|---|
| `TICTECTEOPLUS/` | 틱택토 (`TicTacToe.cpp/.h`, `main.cpp`), 결과 사진 포함 |
| `ticteo/` | 틱택토 초기 버전, 빙고 판정(가로/세로/대각선) 결과 캡처 포함 |
| `main/` | 계산기 (`calculator.cpp/.h`) |
| `틱택토 클래스로 만든거/` | 클래스 기반 틱택토 |
| `버블정렬`, `삽입 정렬`, `선택정렬` | 정렬 알고리즘 연습 |
| `0429만도수업 …`, `240502 만도 스택 push,pop 과제` | 수업 과제 |

> 빌드 산출물(`*.tlog`, `*.obj`, `x64/Debug/…`)이 일부 커밋되어 있습니다. `.gitignore`로 제외하는 것을 권장합니다.
